Optional local game binary slot
===============================

The public source repository does NOT redistribute EA's CardsDLLzf.dll.

Verified compatible DLL:
  ProductVersion: 13.0.1298564
  SHA-256: 35BDAC6BB2F37F4E3F674C5BB979BCB607FEB11CD09105631796D566590FFC06

If your own FIFA 13 installation already has that hash, nothing is needed.
If it does not, use EA App Repair/Update or run IMPORT_MATCHED_CARDSDLL.cmd and
select a legally obtained matching copy. The launcher validates the SHA-256,
backs up the currently installed DLL, and swaps the matched DLL automatically.
